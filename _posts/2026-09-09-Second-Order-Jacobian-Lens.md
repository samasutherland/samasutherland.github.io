I recently discovered the MATS program, and more specifically Neel Nanda's stream. As someone who's just finished a PhD in quantum computing and am looking to work in AI, it seems like the perfect opportunity to build on my ML research taste and skill through exposure to industry leaders.

Neel's stream in particular has a unique application pipeline that asks candidates to complete a 16-hour mini research project attempting to make progress on any open question in mechanistic interpretability. I've recently read Anthropic's new paper "Verbalizable representations form a global workspace in language models" [[1]](#1), and think the results are both impressive and important for our understanding of LLMs. Naturally, I started wondering how to overcome some of the limitations presented in the paper, and how the technique might be extended. I landed on the idea of introducing the second-order differential with respect to the input embedding at a second, separate token location, and thought this idea would be a perfect investigation for the MATS application. While my original MATS project was constrained to 16 hours, this detailed write-up was performed outside that window, as well as a couple of complementary experiments presented in this post.

## Motivation

The Jacobian Lens [[1]](#1) is a powerful recent interpretability technique. By computing the Jacobian of the output of the model with respect to the residual vector of each layer, averaged over prompts and token positions, a per-layer lens matrix is obtained through with layer activations can be analysed. The authors claim the lens reveals properties akin to a verbalisable workspace in human brains, and they perform many experiments showing this workspace reveals concepts and ideas that the model uses for computation, does not explicitly reveal, but can verbalise on command.

However, the J-Lens has some limitations. The J-Lens reveals only a bag of concepts with no inherent structure, does not extend well to early layers, and does not explain the mechanisms governing the space it is analysing. Most notably, a crippling limitation is that all concepts are restricted to single tokens. Progress has been made on some of these limitations. For example, Gong *et al.* [[2]](#2) find that many multi-token concepts are already included in the J-Space, and are directly readable in many cases, with reconstruction of the multi-token concept from the first token possible using a frozen model in a high percentage of cases. Blank *et al.* [[3]](#3) improve the lens' performance on earlier layers by applying layerwise relevance propagation to the backward pass.

The idea of this project is to see if some of these limitations can also be addressed via second order differentiation. By taking the gradient of the output of the model with respect to both a residual vector at layer l and token position t, and an input embedding at token position t′, second order information becomes available that describes not what an activation is disposed to make the model say, but how that disposition depends on which tokens are present elsewhere in the context. While the first-order lens returns a set of single tokens, such an object returns a set of ordered pairs, and it does so without requiring the model to emit either member of the pair, a key limitation restricting the attempts of the original J-Lens paper [[1]](#1) to create multi-token lenses.

In particular, second order information could allow a true multi-token lens. By scoring concepts over the first order J-Lens, followed by the next token pair score, discoverable multi-token concepts could be surfaced programmatically. Going beyond this, chaining pairwise interactions could allow for arbitrary-length concepts to be discovered. Beyond multi-token concepts, the same object imposes structure on the relationship between the workspace and the prompt that produced it. It reveals the dependence of the J-Space on other tokens in the context, giving a cheap estimate of how the workspace will change under a counterfactual edit. Specifically, this would go beyond correlational effects, as negative causality would be equally as visible as positive. Finally, this object would also provide proposal mechanism for context interventions to elicit or suppress desired "thoughts" in the model.

## Scope Reduction

While I was excited to build and investigate this second order object, I quickly realised that that would be well beyond the scope of 16 hours, so instead I decided to investigate whether the second-order J-Lens was even worth investigating. Two things could potentially block the feasibility of the second order object. The first is vanishing gradient due to activation saturation. The flavour of this work is very similar to attribution patching [[4]](#4), in which they found that saturation of activation functions results in very small gradients, limiting gradient based methods. During this project, I directly investigated the gradient sensitivity of input perturbation in two regimes: counterfactual substitution, where the effect of substituting an input token *before* the J-Lens readout was examined, and token gated routing, where the second-order effect of substituting a token *after* the J-Lens readout position was investigated. The second major viability blocker is the computational overhead. The base J-Lens has dimensionality d × d, where d is the embedding dimension. The full second order object is d × d × d, requiring a factor of d more storage and, critically, a factor of d second-order differentiation passes per prompt, which could quickly become prohibitively costly at even moderate embedding dimensions. In this project, I assume the infeasibility of computing the second-order J-Lens (valid for computation restricted scenarios like my own or enormous frontier models) and investigate if low-rank sketching is a viable approximation for the full rank lens. I investigated both these feasibility blockers using Qwen3.5-4B, with its associated pretrained n = 1000 J-Lens from Neuronpedia.

## Feasibility Study 1: Gradient Sensitivity

### Counterfactual Replacement

The first thing I measured is the effect of counterfactual replacement on both the J-Lens and the output. This is a first order effect, and analyses how the J-Lens probe and the final token in the sequence are affected by replacement of a high importance upstream token. To measure this, I created a dataset of multi-hop statements. Each statement is based off a trio of tokens - the input, the bridge, and the output. Qwen3.5-4B's tokenizer is slightly surprising on which inputs are tokenized into a single token, so an initial search over candidate tokens over a variety of topics was performed to find triplets whose entries are all single tokens. These entries were then embedded into a variety of carrier sentences. For example, with the triplet `MAD` → `madrid` → `spain`, a carrier sentence might write *Passengers landing at MAD have arrived in the country of Spain*. Importantly, this sentence requires computation of the intermediate concept `madrid`, despite it not appearing in the token stream—exactly what the J-Lens was designed to detect. Furthermore, the sentence is constructed so that the overwhelmingly likely next token is the desired answer. By then introducing a second triplet of the same form `IST` → `istanbul` → `turkey`, we can measure the sensitivity of both the bridge and the output to a continuous change in the input embedding x = α·MAD + (1 − α)·IST.

31 triplet pairs were generated, with 5 carrier sentences each. These triplets and carrier sentences were then filtered to ensure that :

1. Swapping the input token swaps the ranking of the output tokens
2. The bridge appears somewhere in the J-Lens of the output
3. The fully tokenized carrier must have the answer at its last token

After that, we have a collection of prompts that have single-token inputs, bridges, and outputs with guaranteed presence of the bridge in the intermediate J-Space. Note that the bridge position is chosen to be the token position with the highest total occurrences of the bridge token in its J-Lens over all layers across both triplets.

Note that these examples were deliberately selected to contain strongly coupled lexical substitutions, which is ideally where the strongest coupling effect will be seen between the input and outputs. This means, however, that the gradient analysed here is not necessarily representative of that between arbitrary token/J-Lens pairs.

#### Results

First I directly analysed the output logits as a function of α. This was measured by projecting the output vector on the 1-dimensional subspace spanned by the vector connecting the two output tokens (in our example, `span` and `turkey`), with the first option mapping to 0 and the second mapping to 1. The behaviour of the output with respect to α is shown in the following figure, with one black line representing one input prompt pair.

![answer_sweep](/assets/img/second-order-j-lens/answer_sweep.png)

Aside from some outlier prompts, which I unfortunately did not have time to investigate, the majority of sweeps follow a logistic-type curve, smoothly stepping from 0.0 to 1.0 as α sweeps from 0.0 to 1.0. A very similar shape is found in the bridge J-Lens representation, where a similar sweep was performed and the J-Lens vector projected onto the two bridge token targets.

![bridge_sweep](/assets/img/second-order-j-lens/bridge_sweep.png)

This graph shows the sweep at layer 20, which is the layer at the midpoint of the working band. To measure the effect, the transition width (amount of alpha between 10% and 90% change), gradient at α = 0, and gradient at α = 1 were aggregated and plotted below:

![transition_sweep](/assets/img/second-order-j-lens/transition_sweep.png)

The gradient is computed in the rescaled space, which progresses from 0 at α = 0 to 1 at α = 1, meaning a perfectly linear response would have a gradient of 1, and a value of 0.1 would represent a sensitivity only 10% of linear. The transition width falls monotonically with depth, from 0.64 at the first layer to 0.24 at the last. At the endpoints, the bridge remains relatively fixed, with a transition period occurring with increasing narrowness at deeper layers, indicating that the gradient response will be strongest at early layers. The endpoint gradients corroborate this. The median slope falls from 0.53 at layer 0 to below 0.2 past layer 20, and the lower quartile reaches zero at twelve separate layers, meaning that for at least a quarter of prompts the endpoint derivative carries no signal at all. Since the second-order object would have to be evaluated at real tokens, this is the regime it would operate in. Two caveats temper this. Rescaling divides each curve by its own total change, so prompts where the swap has little effect have their noise amplified to full scale, and the zeros in the lower quartile may be an artefact of that normalisation rather than genuine saturation. The sweep also interpolates linearly between the two token embeddings without norm matching, so the interpolated vector passes through a shorter, less token-like region near the middle, and some of the sharpness of the transition may belong to that path rather than to the model.

The consequence is that a derivative taken at either endpoint underestimates the effect of the swap, increasingly so with depth. Where the transition is sharp, the endpoints sit in the flat regions on either side of it, and the gradient there sees only the tail of the response rather than the response itself. This is a milder version of the failure mode documented for attribution patching by Kramár *et al.* [[4]](#4), in which a first-order approximation produces systematic false negatives when the perturbed quantity feeds a saturated function, and the narrowing of the transition with depth is consistent with the all-or-none ignition behaviour that Gurnee *et al.* [[1]](#1) report above the workspace onset. The attenuation is not severe enough on its own to rule out a gradient-based object, but it does mean the deep layers, where the workspace sits, are the ones where the estimate is weakest.

### Token Gated Routing

The counterfactual sweep measured above moves a token that sits before everything else, eliciting a more traditional first-order effect on the activation downstream. To measure specifically the second-order mixed derivative alone, the position of the input token must be after the position that the J-Lens is read. This ensures the read activation is causally independent of the swept token, so the only route by which the gate can modulate that activation's effect on the output is the interaction term. To measure this, a second dataset was created. The trios are copied from the counterfactual bank, so their single-token status is already known, and only the gate word is new. The gate word is swept between `not` and `certainly`, chosen as a negation pair that are each a single token, allowing for a sweep like in the previous section. Reusing the trio `MAD` → `madrid` → `spain` from above, consider *Passengers landing at MAD have {gate} arrived in the country of Spain*. We can measure the sensitivity of the output to a continuous change in the gate embedding x = α·certainly + (1 − α)·not, with the J-Lens read at `MAD`.

6 trios were generated, with 3 carrier sentences each. These trios and carrier sentences were then filtered to ensure that:

1. Swapping the gate word moves the answer logit by at least a small margin
2. The bridge appears in the J-Lens at the read position

After filtering, a collection of prompts is obtained where varying the gate word has direct consequence on the output logit, but no causal effect on the prior J-Lens. By measuring the gradient of the output logits with respect to the J-Space at the read token, we can measure the second order effect that later context has on the effect of the J-Space on the output.

This gives 18 prompts, which is a small bank. The effect sizes are consistent enough across trials (except for a couple of outliers) that I do not think the conclusions are sample-limited, however I would not put 100% faith in these results until more samples are analysed. A second restriction is the limitation of a single gate pair. `not`/`certainly` was the only negation pair I tried, and a wider set of gate words would test whether the step at α = 0.4 is a property of gating or of this particular pair.

Again, these examples were deliberately selected to contain strongly coupled lexical substitutions, which is ideally where the strongest coupling effect will be seen between the input and outputs. This means, however, that the gradient analysed here is not necessarily representative of that between arbitrary token/J-Lens pairs.

#### Results

The following figure shows how the magnitude of the gradient of the output token with respect to the bridge changes as the input embedding of the later token is modified.

![gate_norm_sweep](/assets/img/second-order-j-lens/gate_norm_sweep.png)

Here, because the second endpoint is not well defined (a `not` gate does not fix a specific output token), we take all differences relative to the starting point. The magnitude is rescaled by the gradient magnitude at the token `certainly`, meaning all lines start at 1.0 by definition. Apart from the clear outlier (which again I unfortunately did not have time to directly investigate), the median shows a clear trend of a step function occurring at α = 0.4 to a lower gradient magnitude. The decrease of the gradient magnitude from `certainly` to `not` is expected: the prompt "Passengers landing at MAD have certainly arrived in the country of" couples the output token much more tightly to `MAD` than the prompt "Passengers landing at MAD have not arrived in the country of" because the former case has only one correct answer depending on the airport code while the latter has many correct answers.

While the gradient broadly follows the expected pattern, the specific shape of a step at α = 0.4 results in extremely flat endpoints, indicating a much smaller second order gradient response in this situation compared to the first-order response of counterfactual replacement. Plotting the width of this transition as well as the gradient at each endpoint is plotted below. The width is again taken to be the total alpha between the 10% and 90% change landmarks. Due to noise, outliers are removed and the gradient at each endpoint is computed by fitting a straight line to the last/first k=4 points prior to taking the gradient.

![routed_gradients_robust](/assets/img/second-order-j-lens/routed_gradients_robust.png)

This figure shows widths and gradients for token gated routing, in which the swept token is causally downstream of the read position so that the interaction term is the only available route. Here the measured quantity is the magnitude of the first-order gradient itself, ‖∂ answer/∂h‖ at the read position, normalised by its value at the `certainly` endpoint, so that sweeping the gate traces out the mixed second derivative directly. Over the full sweep this quantity falls by a median of 22%: weakening the gate attenuates the pathway from the read position to the answer rather than redirecting it, which is what the near-constant cosine to the lens direction over the same sweep confirms.

For all layers, the step function has a sharp transition. The median width sits between 0.06 and 0.18 for the first twenty-three layers, reaching a minimum of 0.06 at layer 7, and broadens only in the final layers, where it reaches 0.48 at layer 26. Almost all of the attenuation therefore occurs within a narrow band of α near the middle of the sweep, with both real-token endpoints sitting on flat plateaus either side of it.

The endpoint slopes reflect this. Estimated by a four-point least-squares fit at each end, the median slope at the `certainly` endpoint holds between 0.08 and 0.15 across the network, while at the `not` endpoint it falls from 0.11 at layer 7 to below 0.05 through layers 13 to 23. Against a total change of 0.22 over the sweep, a derivative taken at a real token and extrapolated linearly therefore recovers roughly a third of the true effect on the `certainly` side and under a fifth on the `not` side, with the weakest estimates falling in the middle layers where the workspace sits.

Two properties of the sweep limit how far this generalises. The gradient is measured with respect to α rather than with respect to the embedding itself, so it captures only the component of the mixed derivative along the line joining the two gate tokens, and says nothing about the remaining d − 1 directions. That line is also not a direction the embedding would ever vary along in normal operation: `not` and `certainly` are near-orthogonal, with a cosine of 0.03, so linear interpolation between them passes through a region of norm 0.49 against 0.68 at the endpoints, the reduction expected for orthogonal vectors of equal length. The step at α = 0.4 sits close to that minimum, and I cannot rule out that its sharpness reflects the model responding to an interpolated vector whose norm and direction are both atypical of real tokens, rather than to gating as such.

The interaction the mixed derivative is intended to capture exists, since the pathway strength does change by 22% between the two gate words. But it takes the form of a step function, and the derivative must be evaluated at real tokens, which is precisely where the response is flattest. A gradient-based estimate would therefore systematically understate the interaction, and would do so unevenly: the asymmetry between the two endpoints means the same pair scores differently depending on which token is treated as the baseline.

## Feasibility Study 2: Sketching Viability

In the original J-Lens paper, Gurnee *et al.* [[1]](#1) investigate the dimensionality of the J-Space across layers. The figure below shows their results:

![J-Space dimensionality across layers](/assets/img/second-order-j-lens/jspace_dimensionality.png)

In Figure (a) they find a small effective rank in layers earlier than their defined workspace, moderate but increasing rank inside the workspace, and then a sharp increase to a high-rank space immediately after the workspace. These conclusions are strengthened by Figure (b). Here, using fitted sparse autoencoders, they measure how many sparse vectors can be added before the marginal reconstruction accuracy benefit becomes equivalent to random vectors, and find a sharp uptick at the start of the workspace, while the total number is small compared to the dimension of the J-Space over all layers. The combination of these plots is strong evidence that the J-Space exhibits some low-rank structure.

This result implies that it is not necessary to compute the entire J-Lens at full rank, a factor critical to the second-order object, since a low rank computation can improve feasibility by reducing overhead. In particular, a low-rank approximation of the J-Lens can be computed directly in from backward passes without ever first materialising the full object. This can be done be replacing the d one-hot cotangents injected in the backward pass by a series of sketching vectors that perform a low-rank subspace sampling of the true J-Lens object.

To evaluate the accuracy of a low-rank approximation, the J-Lens of Qwen3.5-4B was investigated. Three sketching bases were chosen: a basis of random vectors, evaluating the random sketching accuracy; the ordered right-singular vectors of the unembedding matrix, for a measure of performance using a task-relevant sample set; and the ordered right-singular vectors of each layer's readout matrix, formed by composing the unembedding with that layer's J-Lens. Since this basis is derived from the lens it is trying to approximate, it is not achievable in practice; it serves as a reference for what a well-chosen, lens-aware sampling set can achieve. The basis used here is the right-singular basis of the readout-composed J-Lens, so it should be interpreted as an upper bound for readout-weighted performance rather than the optimal rank r reconstruction of the J-Lens in Frobenius norm. Computing this readout-weighted object instead of using a sketching basis computed directly from the right-singular vectors of the J-Lens itself was a mistake, and if I were to repeat this project I would use the latter, which would give a true upper bound on the sketching performance.

A caveat to this method is that the results below project the published lens into low-rank subspaces rather than fitting a sketched lens from backward passes directly. I did run the direct sketched fit and obtained closely matching results, but did not have time to write it up here.

Note also that this study sketches the first-order lens as a proxy for the second-order object. I take this to be a strong gate, since the second-order object is a larger and almost certainly less compressible target, so failure to sketch the first order suggests failure on the second. It is not a proof, however, and it remains possible that the second-order object has lower effective rank than the lens it derives from.

#### Results

The following figure shows the results of the raw energy metric for each sketching basis across the full range of ranks:

![Raw energy retained by each sketching basis](/assets/img/second-order-j-lens/sketching_energy.png)

The raw energy is the fraction of the J-Lens' Frobenius norm retained by the sketched reconstruction, measuring how much of the lens survives projection onto the sampled subspace irrespective of how the readout weights those directions. The line for each basis is the mean over all layers, and the shaded area is the range of values across layers. The dashed line is the chance level, which for a random subspace is the square root of the ratio of the sketch rank to the embedding dimension. The x axis represents the number of sketching vectors used.

The random basis sits on the chance line at every rank, since a randomly oriented subspace captures a fraction of the lens equal to its share of the dimensions regardless of the structure the lens contains. The unembedding line marginally outperforms chance until rank 512, where it starts to marginally *underperform* chance. This implies that the first 512 right-singular vectors of the unembedding matrix carry marginally more useful information than random, while after 512 the vectors seem to pick directions *worse* than random - i.e. that are explicitly poorly aligned with the target subspace, despite being a task-relevant sampling set.

The oracle basis outperforms chance at every rank. At rank 8 it retains roughly twice the energy of the other two bases, and by rank 128 it retains 0.41 against 0.22 for the random basis, a rank at which the random basis would need approximately four times as many sketching vectors to match it. The spread across layers is much wider for the oracle basis, indicating that the low-rank structure it exploits is far stronger in some layers than others, consistent with the layerwise dimensionality reported by Gurnee *et al.* [[1]](#1).

The next figure shows the results of the `pass@k` metric for each sketching basis up to a maximum dimension of 256. In the `pass@k` metric, a collection of prompts with intermediate ideas is defined. For each prompt, the rank of each intermediate idea is measured for every layer at a specific token position (where a lower rank indicates a more importance). The rank of the best scoring layer is recorded as the rank of that (prompt, intermediate) pair. These rank results are pooled across prompts and intermediate ideas. Then, the fraction of results with rank ≤ k is computed for ranks k = 1 … 100 at 6 sampling points with log spacing. The total area under this curve is then calculated and normalised by log(100) as a proxy metric in [0, 1] for how powerful the lens is at surfacing these intermediate ideas.

![pass@k for each sketching basis](/assets/img/second-order-j-lens/sketching_passk.png)

The x axis represents the number of sketching vectors used, while the y axis represents the pass@k metric normalised by the performance of the base J-Lens, meaning that a value of 1 means the new lengths matches the performance of the base J-Lens. Each sketching basis is represented by a line showing the average result over six different evaluation sets, and the area represents the range of values over that set. Two horizontal lines show the normalised performance of the released lens and the logit lens.

This figures shows that the sketching basis stemming from the right singular vectors of the unembedding matrix outperform a random sketching basis, but massively underperform those of the oracle basis. Furthermore, while the oracle basis increases in performance quickly with rank, the other two bases improve only slowly.

The horizontal dotted line represents the performance of the logit lens. The logit lens outperforms all our sketched J-Lenses, except for the rank-256 oracle sketched lens, whose best performance actually outperformed the base J-Lens (resulting in a score > 1).

This is strong evidence that sketched approximations of the J-Lens based on random basis vectors or the right singular vectors of the unembedding matrix are uncompetitive. However, the oracle lens achieves comparable performance at rank 256, only 10% of the full lens' parameters. This indicates that an active method where sketching vectors are incrementally selected to maximise the amount of structure captured at each stage, similar to the process used in randomised SVD which uses feedback to guide sketching vectors, could be used to approach an effective low-rank retrieval method for the J-Lens.

Taken together, the two metrics tell a consistent story. The `pass@k` results show that neither the random nor the unembedding basis recovers enough of the lens to be useful at the ranks tested, both falling below even the logit lens, while the oracle basis reaches comparable performance to the full lens at rank 256. The raw energy results show why: the two practical bases retain no more of the lens than an arbitrary subspace of the same size, whereas the oracle basis retains several times as much. The failure therefore shows that while low-rank structure is present, the two sketching regimes chosen here are not enough to capture that structure. Since the second-order object requires a factor of d more differentiation passes than the first-order lens, and low-rank sketching is my proposal for making that cost tractable, this points clearly towards future work investigating active methods that uses the sketched measurements already being collected to guide the choice of subsequent sketching vectors, in the manner of randomised SVD, rather than fixing the sampling set in advance.

## Conclusion

I set out to determine whether a second-order Jacobian lens was worth building, and based on the evidence gathered here, the answer is likely no.

Feasibility study 1: gradient sensitivity showed that the second order interaction of the J-Lens is real. Counterfactual substitution of an input token shows a first-order effect of moving the bridge representation, and token gated routing, where a "gate" token is swapped, shows a second-order dependency by attenuating the dependency of the output token on the read position by a median of 22%. But in both regimes the response can be well approximated by a step function, with fixed-token endpoints sitting in plateaus. Since the swapping mechanic here changes *input* embeddings, in normal operation these are discrete choices defined by the embedding matrix, as opposed to the continuously varying output of the residual stream that the J-Lens analyses. A derivative evaluated at a real token therefore recovers a minority of the effect, and does so unevenly across layers and across the two endpoints. This is a weaker obstacle than outright saturation, and it does not rule out a gradient-based object, but it does mean such an object would systematically understate interactions and would be least reliable in the deep layers where the workspace sits, which is precisely where you would hope the object would give the most signal.

On computational overhead, low-rank structure is present in the J-Lens but neither practical sketching basis tried in this project finds it. Random vectors and the right-singular vectors of the unembedding matrix both perform at a similar level to an arbitrary subspace of the same size, and both fall below the logit lens on the readout task at every rank tested. The oracle basis reaches the performance of the full lens at only 10% of its dimensions, which shows that a sufficient subspace exists; the difficulty is choosing it without reference to the (uncomputed) lens. Since the second-order object needs a factor of d more differentiation passes than the first-order one, my proposal of sketching to recover low-rank behaviour is inadequate and a more sophisticated technique is required.

The natural next step on the sketching side is an active method in the manner of randomised SVD, which uses the measurements already being collected to choose subsequent sketching vectors. This is a promising direction as it will automatically find a basis superior to the fixed bases tried, as shown by the oracle results. However, the overhead of performing this sampling is a question for future work. On the gradient side, the honest conclusion is that the endpoint derivative is likely the wrong instrument for a step-shaped response, and recovering the interaction would require measuring the transition directly, at which point the cost advantage that motivated the second-order formulation over explicit activation patching largely disappears.

The broader lesson I take from this is about sequencing. My initial plan was to build the object and characterise what it revealed, and what I actually did was ask whether two specific properties it depends on hold. Narrowing the scope was the right call, but I ran both feasibility studies in parallel, and each turned out to have more depth than I anticipated. Working through one question to this level of detail before starting the second would have let the first inform the second, and would have produced a better result than splitting the time between them.
